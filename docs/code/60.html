VAT rate for commodity code 60 in the EU — Programming, broadcasting, news agency and other content distribution services

Commodity code 60 (Programming, broadcasting, news agency and other content distribution services) carries rates from 4% to 13.5% across the 3 EU member states that report a rate for it. The full table is below, and the same data is available as JSON.
